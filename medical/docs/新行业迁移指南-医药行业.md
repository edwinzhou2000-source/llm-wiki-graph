# LLM-WIKI 知识库 — 新行业迁移指南 (医药行业 · fushun)

> 写给接手迁移的同事。本文档假设你已经拿到完整项目代码，目标是部署一套 fushun 医药知识库 demo。

---

## 零、这是什么？

一个 **品牌无关的知识库系统**。当前运行的是 adidas 产品知识库（~6800 个产品页、775 个系列页、75 个科技概念页），支持 AI 智能问答、文档上传自动入库、3D 知识图谱、三级自维护。

**架构一句话**: 一个配置文件 + 一堆 markdown 文件 + Python 服务器 + AI 模型。

所有品牌相关的内容都在一个文件里：`kb-config.yml`。换行业 = 改这一个文件 + 准备素材 + 跑脚本。

---

## 一、系统依赖

在新电脑上先装这些:

```bash
# 1. Python 3.11+ （必须）
python3 --version

# 2. PyYAML
pip3 install pyyaml requests jieba

# 3. Bun (用于 gbrain 搜索引擎)
curl -fsSL https://bun.sh/install | bash
```

可选（如果不用图片提取和 OCR）:
- cloudflared (用于公网隧道)
- hermes CLI (用于 AI 自动收录)

**API Key**: 需要在 `~/.hermes/.env` 里配置 `DEEPSEEK_API_KEY` 和 `PORTAL_PASSWORD`。向 edwin 要 key 或者用自己的 DeepSeek API key。

### 品类设计说明

上面是参考模板。实际上你只需要决定两件事:

1. **产品怎么分类?** → `categories` 部分。比如:
   - 按注册分类: 处方药 / OTC / 医疗器械 / 保健品
   - 按治疗领域: 心血管 / 肿瘤 / 抗感染 / ...
   - 按剂型: 片剂 / 注射液 / 胶囊 / ...
   - 可以嵌套（最多 3 层）

2. **标签体系怎么定?** → `taxonomy.valid_values` 部分。这些是受控词汇，AI 和被搜索都会用:
   - `type`: 产品类型（对应上面的 category 大类）
   - `series`: 产品系列名
   - 行业特有维度: 如 `dosage_form`（剂型）、`indication`（适应症）、`tech`（技术平台）

## 四、需要改动的代码文件

框架本身已经是品牌无关的，但有 6 个文件里残留了 adidas 特有内容:

| 文件 | 改什么 | 难度 |
|------|--------|------|
| `kb-config.yml` | 全量重写（按上面的模板） | 中 — 需要定义品类 |
| `_link_concepts.py` | `_NON_TECH_BLACKLIST` — 约 80 个 adidas 术语 (samba, boost 等) 替换或清空 | 低 |
| `vision-ingest.py` | AI 提示词 "你是 adidas 产品..." → "你是 fushun 医药..." | 低 |
| `server.py` | `_BRAND_DIRS` 映射表 (三叶草产品→三叶草 等) | 低 |
| `sw.js` | 1 行缓存名 | 低 |
| `generate-ppt.js` | 几处 "adidas" 硬编码 | 低 |

**实操**: 用 VS Code 全局搜索 `adidas`，逐个替换为 `fushun`。约 15 处。

## 五、你需要准备的素材

系统只是一个空壳。知识库的价值 = 里面有什么内容。内容的来源:

### 按优先级排序

| 优先级 | 素材类型 | 说明 | 能产生多少内容 |
|--------|----------|------|---------------|
| ⭐⭐⭐ | **Excel 产品清单** | 列: 产品名、类别、剂型、适应症、主要成分、价格。脚本批量生成 markdown 页面 | 几百到几千页 |
| ⭐⭐⭐ | **PDF/PPT 培训资料** | AI 自动逐页提取产品信息并入库。需要 DeepSeek API key | 一份 PDF 约产出 20-50 页 |
| ⭐⭐ | **产品手册/说明书** | 同上，质量更高 | 同上 |
| ⭐⭐ | **官网内容抓取** | 需要额外工具 | 不定 |
| ⭐ | **零素材** | 纯手工逐条录入 | 慢，但可控 |

### 最小可行 demo 素材

如果你想快速搭一个能演示的 demo，最少需要:

1. **20-50 个产品的 Excel 表**，包含:
   - 产品名称
   - 所属分类 (处方药/OTC/器械)
   - 适应症 / 用途
   - 剂型
   - 主要成分 / 技术特点
   - 一句话简介

2. **3-5 个产品系列的说明** (一段话即可)

3. **5-10 个技术/概念说明** (如: 缓释技术、靶向递送、纳米制剂...)

没有素材也行 — 可以先建空框架，然后通过 `🤖 AI全自动收录` 功能逐个上传说明书 PDF 让 AI 自动提取。

### Step 5: 导入产品内容 (时间取决于素材)

**方案 A: 有 Excel 产品清单**

写一个简单的 Python 脚本，读取 Excel 的每一行 → 生成对应格式的 .md 文件:

```python
# 示例：excel_to_md.py
import pandas as pd, os

df = pd.read_excel("products.xlsx")
for _, row in df.iterrows():
    # 生成 frontmatter + markdown
    content = f"""---
title: "{row['产品名']}"
type: "{row['分类']}"
series: [{row.get('系列', '')}]
dosage_form: "{row.get('剂型', '')}"
indication: "{row.get('适应症', '')}"
tags:
- {row['分类']}
- {row.get('适应症', '')}
---

# {row['产品名']}

{row.get('简介', '')}

## 适应症

{row.get('适应症', '')}

## 主要成分

{row.get('成分', '')}
"""
    # 按分类放入对应目录
    dir_map = {"处方药": "处方药", "OTC药品": "OTC药品"}
    cat_dir = dir_map.get(row['分类'], "处方药")
    slug = row['产品名'].lower().replace(' ', '-').replace('/', '-')
    path = f"{cat_dir}/{row.get('适应症', '')}/{slug}.md"
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, 'w') as f:
        f.write(content)
```

然后重建索引:
```bash
python3 regenerate-graph.py
```

**方案 B: 有 PDF 培训资料**

直接用网页界面上传:
1. 打开 `product-hub.html`
2. 拖拽 PDF 到上传区域
3. 选 `🤖 AI全自动收录` → 自动提取入库
4. 或选 `🔍 上传并审核` → AI 生成提案 → 你审核后入库

**方案 C: 无素材**

在网页界面手动创建 → 标签页 → 逐个添加。或让 AI 帮你生成一些 demo 数据:
- 给 DeepSeek 一个 prompt: "生成 20 个虚构的 fushun 医药产品数据，包含药品名称、适应症、剂型、成分"
- 将输出格式化为 markdown 页面

## 七、常见问题

### Q: 启动报错 "PORTAL_PASSWORD must be set"
在 `~/.hermes/.env` 里加上 `PORTAL_PASSWORD=你的密码`

### Q: gbrain CLI 找不到
```bash
# 检查
ls ~/gbrain/src/cli.ts
# 如果没有，找 edwin 要 gbrain 仓库
```

### Q: `_link_concepts.py` 里黑名单怎么改
清空即可，等后续发现误匹配再添加:
```python
_NON_TECH_BLACKLIST = set()  # 医药行业暂无黑名单
```

### Q: 怎么判断改完了？
```bash
# 搜索残留的 adidas 引用（忽略 node_modules 和 .git）
grep -r "adidas" --include="*.py" --include="*.html" --include="*.js" \
  --exclude-dir=node_modules --exclude-dir=.git . | grep -v "knowledge-graph-3d\|node_modules"
# 应该只剩下 knowledge-graph-3d.html 里的 "adidas"（那是旧示例数据，可以不管）
```

### Q: 品类设计完全没头绪怎么办？
先用最简单的分类:
```
categories:
  - 药品
    - 处方药
    - OTC
  - 医疗器械
  - 保健品
  - 技术平台
  - 产品系列
```

后续随时可以改 `kb-config.yml` 再跑 `bash setup.sh` 重建（已有内容的目录不会丢失）。
